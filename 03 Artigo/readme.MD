O trabalho final da Disciplina é a escrita de um artigo para o Mining Challenge do MSR 2026. O envio para o congresso não é obrigatório, mas a entrega no formato da conferência sim

[Mining Challenge Call for Papers 2026] (https://2026.msrconf.org/track/msr-2026-mining-challenge)

A proposta deverá ser apresentada no dia 01/10.
As apresentações dos trabalhos na disciplina acontecerão nos dias 24/11, 26/11, 01/12 e 03/12.
Porém, TODAS as duplas devem estar com o artigo e apresentação prontos no dia 24/11, quando acontecerá o sorteio da ordem de apresentação.


## Entregas

### Proposta
Deverá ser entregue no dia 01/10 no GitHub da dupla e feito um pitch rápido em aula:
- Nomes dos integrantes da dupla
- Quais perguntas de pesquisa serão respondidas (o call for papers tem sugestões, mas podem ser outras)
- Que tipos de análises a dupla pretende fazer

### Resultado Final
#### Análise de Dados
- Deverá ser entregue no dia 24/11 no GitHub
	- Como as analyses foram feitas e como podem ser reproduzidas 
	- Análise Quantitativa: Scripts usados para análises quantitativas, charts gerados
	- Análise Qualitativa: Se foi feito, passo a passo documentado além do resultado final
#### Artigo	
- Deverá ser entregue no dia 24/11 no GitHub o artigo final com tudo consolidado, no formato solicitado pela conferência na página de call for papers.
- Olhem os artigos dos mining challenges passados! É uma ótima forma de entender como resportar os resultados
- Normalmente a estrutura dos artigos é essa:
```
Abstract
Introduction (citando as perguntas de pesquisa)
Dataset
Analysis and Findings 
Conclusion
References
``
